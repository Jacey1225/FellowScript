# FellowScript

A faith-based Bible study platform built to foster meaningful connections between people who seek to grow in their faith together.

## About

FellowScript is a community-driven Bible reading app where users can read scripture, highlight and annotate text, and connect with like-minded believers. The platform is designed around the goal of building impactful relationships that fan into flame the gift of God.

## Features

- **Digital Bible Reader** — Navigate by book and chapter with a built-in search bar
- **Text Highlighting** — Highlight scripture in multiple colors (yellow, green, pink, blue)
- **Notes** — Create public or private notes on highlighted text or alongside the Bible
- **Community Highlights** — Filter and view other users' public highlights on scripture
- **Group Sidebar** — See connected members, send direct messages, or post to a group chat
- **Mobile-First Design** — Clean bottom-tab navigation optimized for one-handed use

## Pages

- **Home** — Introduction to FellowScript's mission with a "Start Reading" call to action
- **Bible Reader** — Full digital Bible with highlighting, notes, and community features

## Design

Mobile-first UI with a warm parchment-and-gold palette. Typography uses Playfair Display for headings and Lora for body text, giving the app a reverent but modern editorial feel.
